# QR Based Attachment Management System

A MERN stack web application for managing machine attachments in a garment factory using unique QR codes.

## Overview

This system allows garment factories to assign a unique QR code to every machine attachment based on its module and attachment type. Workers can scan QR codes using their mobile phones to instantly view the correct attachment details, while administrators can manage modules, attachments, QR codes, and scan records through a centralized dashboard.

## Features

- Admin authentication
- Module management
- Attachment type management
- QR code generation
- Bulk QR code generation
- Mobile-friendly QR scanning
- Scan history tracking
- Responsive dashboard
- Search and filtering

## Technology Stack

- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT
- **QR Generation:** QRCode
